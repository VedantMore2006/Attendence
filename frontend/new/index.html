System Architecture

How the AI-Powered Biometric System Works

1. Image Capture

High-resolution webcam frame is captured and encoded in base64.

2. Fast API Backend

Image is decoded and processed by the high-performance FastAPI server.

3. Face Registration & Alignment

RetinaFace detects the face, while the aligner crops and normalizes it.

4. InsightFace ArcFace

buffalo_l model extracts a 512-dimensional embedding vector.

5. SQLite Matching

Cosine similarity matches the vector against stored embeddings instantly.
