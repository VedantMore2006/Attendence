# Glossary

- ArcFace: Face recognition loss function that enforces angular separation between identity clusters in embedding space.
- BlazeFace: Lightweight face detection model optimized for fast CPU/mobile inference.
- Cosine Similarity: Similarity metric based on the angle between two vectors; for normalized vectors, equivalent to dot product.
- Embedding: Fixed-length numerical vector representation of a face in learned feature space.
- FAR (False Accept Rate): Probability of incorrectly accepting an impostor as a valid identity.
- FRR (False Reject Rate): Probability of incorrectly rejecting a legitimate identity.
- Glassmorphism: UI style using translucent surfaces, blur effects, and layered backgrounds.
- InsightFace: Open-source face analysis framework used here for ArcFace-based embedding extraction.
- L2 Normalization: Vector scaling operation that sets Euclidean norm to 1.
- Liveness Detection: Methods used to distinguish a live person from spoof artifacts such as photos or screens.
- MediaPipe: Cross-platform machine learning framework used here for face detection.
- ONNX (Open Neural Network Exchange): Interoperable model format for machine learning inference.
- ONNX Runtime: Execution engine used to run ONNX models on CPU or accelerator backends.
- Pydantic: Python validation library used by FastAPI for typed request and response models.
- SQLite: Serverless file-based relational database engine.
- Uvicorn: ASGI server used to run FastAPI applications.
- WebRTC: Browser standard enabling real-time media capture and communication, including webcam access.
